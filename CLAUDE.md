# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

**Zizi Byte** — "Learn in bytes. Think in leaps." Adaptive AI micro-learning platform that transforms dense course materials into personalized, analogy-driven learning experiences. AIE9 Certification Challenge submission.

Three modes: **LMS** (byte-sized analogy learning, Build mode, Share), **Content Pipeline** (research → dedup → RAG → post + image), and **Chat** (KG+Dense → Cohere Rerank → analogy-first grounded answer).

## Commands

```bash
# Install
uv sync

# Start Qdrant (required before running app or evals)
docker compose up -d

# Ingest course materials (run once, or after adding new modules)
uv run python scripts/ingest_courses.py
uv run python scripts/ingest_courses.py --dry-run   # list files only
uv run python scripts/ingest_courses.py --modules 04,11

# Start the Chainlit chat app
uv run chainlit run app.py
# → http://localhost:8000

# Start the LMS API server (FastAPI)
uv run python api_server.py
# → http://localhost:8001

# Start the LMS frontend (Next.js)
cd zizi-lms && npm install && npm run dev
# → http://localhost:3000

# Bulk regenerate analogies (all concepts except embeddings/HyDE), with Claude evaluation
uv run python scripts/regen_analogies.py --run

# Bulk regenerate DALL-E images for all active analogies
uv run python scripts/regen_images.py --run

# Pre-generate and cache all Claude interactions
uv run python scripts/regen_interactions.py --run

# RAGAS evaluation pipeline (in order)
uv run python evals/synthetic_data_gen.py --size 15
uv run python evals/ragas_baseline.py --delay 1.0
uv run python evals/ragas_hyde.py --delay 1.0
```

## Architecture

**Entry point**: `app.py` (Chainlit) — detects intent from message keywords, routes to LMS link / Content Pipeline / KG view / Chat.

**LMS** (`api_server.py` + `src/lms/` + `zizi-lms/`): FastAPI bridge (port 8001) + Next.js 14 frontend (port 3000). Topics from KG; bytes generated by `ByteGenerator`; interactive widgets by `ClaudeInteractionGenerator`; Share triggers content pipeline.

**Content pipeline** (`src/agents/content_pipeline.py`): LangGraph graph with nodes: `research → merge_topics → dedup_check →[conditional]→ retrieve_context → generate_post → generate_image → ingest_post`. The `dedup_check_node` is the agentic decision point — branches to `inform_duplicate` if cosine similarity > `DEDUP_THRESHOLD`.

**Chat pipeline** (`src/agents/chat_pipeline.py`): `kg_retrieve → generate_answer`. Uses `KGRetriever` + `DenseRetriever` (k=15 each) → Cohere Rerank.

**Retrieval stack** (`src/retrieval/`):
- `DenseRetriever` — baseline, embeds raw query
- `HyDERetriever` — generates hypothetical document, embeds that instead (RAGAS Task 6)
- `KGRetriever` — KG traversal (NetworkX) + Dense on related topics (used in chat)
- All implement the `Retriever` protocol from `base.py`

**Memory** (`src/memory/`):
- `qdrant_store.py` — `upsert_chunks()`, `search()`, `get_langchain_retriever()` (used in evals)
- `topic_graph.py` — NetworkX DiGraph persisted as `data/topic_graph.json`; `get_topic_graph()` singleton

**Tools** (`src/tools/`): `tavily_tool.py`, `x_tool.py` (graceful no-op if `X_BEARER_TOKEN` unset), `image_tool.py` (DALL-E 3)

**Ingestion** (`src/ingestion/`): `CourseIngester` handles PDF/notebook/markdown; `PostIngester` stores generated posts + updates KG

**Config**: `src/config.py` — Pydantic Settings, all values from `.env`. `get_settings()` is `@lru_cache`. Call `cfg.configure_langsmith()` early in startup to enable tracing.

## LMS — Learn Mode (3 tabs)

Each Zizi Byte covers ONE concept:

1. **Hero section** — Topic name badge + emoji + concept heading + first sentence of analogy (teaser). Full analogy lives in the Analogy tab.
2. **Analogy tab** — Full analogy text + "Why It Matters" section.
3. **Interactive tab** — `InteractivePlayer` renders a Claude Sonnet 4.6-generated SVG animation in a sandboxed `<iframe srcdoc>`. Fixed HTML shell with `svg_content`, `steps`, `animate_fn` filled by Claude as JSON. 5 steps, anime.js transitions. Sends `postMessage({type:'step',index:N})` to sync React. CSS theme overrides injected into iframe for light-lavender theme.
4. **Deep Dive tab** — Verbatim RAG-grounded technical explanation + source citations.

**Regenerate**: Opens `RegeneratePanel` — fetches 3 alternative analogies, pre-populates custom input with current analogy. Submitting calls `POST /api/topic/{id}/concept/{c}/p5sketch/regenerate` which regenerates byte + image + Claude interaction.

## LMS — Build Mode

`BuildCard` shows:
- Same `InteractivePlayer` widget (shared API endpoint, same cached data)
- Animated code panel below: current step's code snippet + explanation
- "Download Notebook" button

## LMS — Share Mode

`ShareModal` shows LinkedIn post generation (uses exact byte analogy, ZiziByte attribution) + image download + notebook download. Images served at `/generated/images/xxx.png` by Next.js static — relative paths only (NOT prefixed with API server URL).

## Backend Endpoints (api_server.py)

```
GET  /api/topic/{topic_id}/concept/{concept}/claude-interaction       → cached SVG widget or generate
POST /api/topic/{topic_id}/concept/{concept}/p5sketch/regenerate      → clear+regen all assets, body: {analogy?}
GET  /api/topic/{topic_id}/concept/{concept}/analogy-suggestions      → 3 suggestions
GET  /api/topic/{topic_id}/concept/{concept}/notebook                 → .ipynb download
POST /api/share/create-post                                            → LinkedIn post via content pipeline
```

## SQLite Schema (data/analogies.db)

Two active tables:
- `analogies` — one row per (topic_id, concept, version), `is_active=1` marks live version. Has `image_url`, `image_local_path`, `image_prompt` columns.
- `claude_interactions` — one row per (topic_id, concept), stores `sketch_code` (HTML) + `steps_json` (rich metadata with code_snippet)

Functions in `analogy_store.py`: `get_active_byte()`, `save_claude_interaction()`, `get_claude_interaction()`, `clear_concept_cache()`.

## Key Design Decisions

- `src/` is installed as a package via hatchling — imports work as `from src.X import Y` from any script
- LangSmith tracing is **opt-in** — only activates when `LANGCHAIN_API_KEY` is set
- X.com search is **opt-in** — graceful empty list if `X_BEARER_TOKEN` is unset
- RAGAS uses `SingleTurnSample` + `EvaluationDataset` (0.2.x API from AIE9 Session 10 notebook)
- Qdrant collections are auto-created on first upsert via `ensure_collection()`
- Knowledge Graph JSON is stored at `data/topic_graph.json` (auto-created)
- Claude interactions run in `<iframe sandbox="allow-scripts" srcdoc="...">` — CSS overrides injected via string replace on `</style>` tag for light theme
- Navigation: `loadByte` reads `byteCache` via `useLMSStore.getState()` (not closure) to keep callback stable; AnimatePresence render order is `share → build → byteContent → error → skeleton` — no intermediate placeholder state
- Images stored as `/generated/images/xxx.png` (relative URL served by Next.js at port 3000)
- Topics sorted by `module_number` 01→02→...→11
