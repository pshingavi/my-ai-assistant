# 🎨 Canva Production Checklist

## Setup (Do This First — 15 min)
- [ ] Open Canva → New Presentation → 16:9 Widescreen
- [ ] Set Brand Kit colors: `#0A0A14`, `#7C3AED`, `#06B6D4`, `#A3E635`, `#F59E0B`, `#FFFFFF`, `#94A3B8`
- [ ] Upload fonts: Montserrat (Google Fonts) + Inter (Google Fonts)
- [ ] Set transitions globally: **Dissolve** (sleek, doesn't distract)
- [ ] Enable Magic Media in Apps panel

## Per-Slide Workflow (Repeat for Each)
1. Dark background (`#0A0A14` solid OR dark radial gradient from `#0A0A14` to `#13111F`)
2. Lay text per the copy above
3. Magic Media → paste prompt → generate 4 → pick best
4. Position image as specified (left/right/background with 30% opacity overlay)
5. Add card elements: Shapes → Rectangle → Fill white 6% + Border white 20%
6. Add animations (see below)

## Animation Guide Per Slide
| Slide | Text animation | Image animation |
|-------|---------------|-----------------|
| 1 | Fade In, stagger 0.3s | Slide from right |
| 2 | Rise, large text first | Pan zoom slow |
